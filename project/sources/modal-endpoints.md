# Source note — Modal Endpoints docs

- URL: https://modal.com/docs/guide/endpoints
- Fetched: 2026-10-27
- Readable: Yes.

Key facts:
- Modal Endpoints deploy supported open models (or your own custom weights) as production-ready inference APIs.
- Two serving modes: Shared Endpoints (fully managed, billed per token) and Dedicated Endpoints (isolated capacity/custom models, billed on compute resources, configurable autoscaling incl. scale-to-zero).
- OpenAI- and Anthropic-compatible APIs; proxy tokens act as the API key for an OpenAI-compatible client; affinity routing via the Modal-Routing-Affinity-Key header benefits multi-turn/agent workloads.
- The event page links "Endpoints" as the way Modal's $100 participant credits are used for Meta's open-weights models.
