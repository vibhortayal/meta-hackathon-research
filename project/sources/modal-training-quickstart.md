# Source note — Modal LLM training quickstart ("tools for LLM training" link)

- URL: https://modal.com/docs/guide/training-quickstart
- Fetched: 2026-10-27
- Readable: Yes.

Key facts:
- Easiest training path is Modal Dojo (open-source library, dojo.modal.dev): building blocks, tuned defaults, and observability for SFT and RL post-training; install via `uv add modal-dojo`, set up with `modal-dojo setup`.
- Alternatives: Spindle server (Tinker-compatible API) or Clustered Functions for full control of your own training stack.
- The event page links "tools for LLM training" as one of the Modal offerings available alongside the $100 credit.
